# Novelty and significance

This project is built around a phenotype-agnostic approach to comparative genomics, in which gene retention and loss patterns are analyzed across placental mammals without first assuming a trait or disease phenotype. Unlike targeted studies focused on a single developmental module such as left-right asymmetry, the present work seeks to identify broader evolutionary signatures of coordinated gene loss or retention across a large mammalian phylogeny. The known CIROP/DAND5-type left-right patterning module serves as a motivating positive-control example, providing a benchmark for whether the pipeline can recover a biologically meaningful evolutionary signal before broader discovery is attempted. In this sense, the project differs from prior work by combining explicit assembly provenance QC, Zoonomia-scale comparative analysis, and phylogenetically informed co-loss screening into a single discovery framework for candidate gene modules.

The broader significance of this work is that it provides a systematic way to generate testable biological hypotheses about conserved gene dependencies and pathway-level coordination. Rather than claiming to explain disease directly, the project aims to rank candidate gene pairs and modules whose evolutionary histories suggest shared functional dependence or co-evolutionary constraint. Such modules are valuable because they can point to novel regulatory, developmental, or physiological relationships that may be followed up with CRISPR perturbation, functional assays, or human-genetic validation. Thus, while this project does not by itself solve disease, it offers a scalable framework for moving from comparative evolutionary signal to focused mechanistic investigation.
