To download the content of the entire directory, pls use this command 
 wget --recursive --no-check-certificate https://genome.senckenberg.de/download/TOGA/

The same works for subdirectories. 
Always make sure that there is a trailing backslash (/) at the end of the directory.

Alternatively, we provide a tar.gz file that contains all content, which can be downloaded with
 wget --no-check-certificate https://genome.senckenberg.de/download/all.TOGAdata.tar.gz
